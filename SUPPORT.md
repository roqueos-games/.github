# Ajuda

_English below._

| Você quer                                     | Onde                                                                         |
| --------------------------------------------- | ---------------------------------------------------------------------------- |
| Jogar                                         | [roqueos.com.br/jogos](https://roqueos.com.br/jogos), de graça, no navegador |
| Reportar um bug num jogo                      | uma issue no repositório do jogo                                             |
| Perguntar, sugerir, mostrar o que construiu   | [Discussions](https://github.com/orgs/roqueos-games/discussions)             |
| Problema de conta, login ou recorde que sumiu | **contato@levelhard.com.br** (é o RoqueOS, não o jogo)                       |
| Reportar uma falha de segurança               | [SECURITY.md](SECURITY.md), nunca em issue pública                           |
| Criar um jogo para o RoqueOS                  | comece pelo [jogo-sdk](https://github.com/roqueos-games/jogo-sdk)            |

Para bug, diga em que aparelho e navegador aconteceu e, se der, os passos para repetir. Bug que
a gente consegue repetir é bug que a gente consegue corrigir.

## Support (English)

Play at [roqueos.com.br/jogos](https://roqueos.com.br/jogos). Report game bugs as issues on
the game's repository, with your device, browser and steps to reproduce. Questions, ideas and
show-and-tell go to [Discussions](https://github.com/orgs/roqueos-games/discussions). Account,
login or lost high score problems belong to RoqueOS itself: email
**contato@levelhard.com.br**. Security issues follow [SECURITY.md](SECURITY.md). To build a
game for RoqueOS, start with the [jogo-sdk](https://github.com/roqueos-games/jogo-sdk).
